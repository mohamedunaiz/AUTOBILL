# AUTOBILL — Automated Billing Application

> A modern Next.js billing interface covering product management, camera-assisted input, cart operations, payments and transaction administration.

[![Next.js](https://img.shields.io/badge/Next.js-16-black)](#)
[![React](https://img.shields.io/badge/React-19-61DAFB)](#)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178C6)](#)
[![UI](https://img.shields.io/badge/UI-Tailwind%20%2B%20Radix-38B2AC)](#)

## Features represented in the source tree

- Camera scanner
- Product management
- Shopping cart
- Region selection
- Payment flow
- Transaction history
- Admin pages
- API routes
- Reusable UI components

## Workflow

**Product input → Selection → Cart → Billing → Payment → Transaction → Administration**

## Stack

Next.js 16 • React 19 • TypeScript • Tailwind CSS • Radix UI • React Hook Form • Zod • Recharts • Lucide React

## Run locally

    npm install
    npm run dev

Production:

    npm run build
    npm start

Lint:

    npm run lint

## Security

Never commit environment files, credentials or API keys. Production payment integrations must keep private credentials server-side.
